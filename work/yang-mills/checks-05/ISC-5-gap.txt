Lean theorem massGap_pos:
  ∀ gL : CouplingLength, 0 < gL.num → FracPos (massGap gL)

I.e. if g₀² L_x = num/den with num>0, den>0 then Δ = E(1/2) is a positive fraction.

  0 < gL.num → FracPos (3 * gL.num, 8 * gL.den)
  Δ = 3 g₀² L_x / 8 > 0
