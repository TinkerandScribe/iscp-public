# ISC-3 Candidate — yes

**Topology:** Euclidean/Lorentzian cylinder R × S¹ (spatial circle length L_x). Compact G = SU(N) or U(1).

**Construction:**
1. Lattice-regulated Wilson loops on finite lattice; take a→0, L fixed → continuum Wilson-loop characteristic functional (Ashtekar et al. §4).
2. Extended OS axioms for gauge theories on Ā/𝒢 (Euclidean invariance, reflection positivity, clustering) — verified for this model (§6.2).
3. OS reconstruction → Hilbert space L² of class functions / Cartan characters; Hamiltonian H = −(g₀² L_x / 2) Δ.
4. Spectrum: E_{{m}} = (g₀² L_x / 2) λ_{{m}}; vacuum λ=0; first positive Casimir λ₁ > 0 ⇒ Δ = (g₀² L_x / 2) λ₁ > 0 in continuum units.

**Plane R² note (honesty):** reduced classical phase space is a point; quantum theory is trivial (only constant state). Continuum measure still exists (Driver); mass-gap statement is vacuous/trivial there — not used to claim the interesting gap.
