# Contributing

Thanks for taking a look. ISCP is research code, so we keep changes small and tested.

- Open an issue first for anything bigger than a typo.
- Run `npm test` in `harness/iscp-research` (Node 20+) before sending a pull request.
- New claims need an experiment file in `experiments/` with a KEEP or REJECT result — negative results are welcome.
- By contributing, you agree your work is released under the MIT license.
