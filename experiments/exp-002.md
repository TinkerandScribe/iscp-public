# gxp-exp-002: Library + Structural Requirement

## Task
Implement a small coherent library: `binary_search`, `lower_bound`, `upper_bound`. Full shared unit tests + verified summary of relationships, complexities, and failure modes.

**Injected stress (after base success):** All three functions must share a private helper that itself has independent Ideal State Criteria and tests.

## Results

### Variant A — Pure GXP Loop
- Base library solved in 3 outer iterations.
- On injection, treated as criteria change, failed original verification, captured conflict, and pivoted by rewriting the implementation inside the single loop.
- Result: Success. Clean failure capture. Higher outer iterations after injection.

### Variant B — Hybrid Verification Node
- Base library solved in 2 outer iterations.
- After injection, external gate correctly rejected the old structure; internal confidence dropped; node recovered cleanly.
- Result: Success. Slightly better recovery efficiency than pure GXP.

### Variant C — Minimal Self-modifying Graph (VGTE)
Initial topology (sequential): `Implementer → Tester → Summarizer`

- Base library solved successfully.
- Auditor collected previous failure patterns + the new shared-helper requirement.
- Topology Proposal Loop (itself a GXP node) proposed a **minimal rewrite** (exactly 2 operations):
  - Insert a new `Helper` node between Implementer and Tester.
  - Add a verification edge from Helper back to Tester.
- Hard verification gate checked: no broken sequential dependencies, agent budget safe, types preserved. Gate passed.
- Rewrite committed. Experience Memory recorded the failure class → rewrite mapping.
- Subsequent run used the new topology and satisfied the injected requirement with one fewer outer retry.

**Result:** Success. Topology changed only after verified failure data and only under the hard gate. No uncontrolled mutation. Demonstrated “failures improve topology.”
