## Evolutionary hypothesis

**Canalization:** A well-canalized system absorbs environmental noise without changing essential outcomes. Core genome criteria (binary probeability, no invented evidence, anti-loop related guardrails) should keep verdict bands stable under intake paraphrase/noise, while peripheral domain probes may vary more.

## Task

Generate controlled noise around golden intakes (paraphrase, reorder sections, mild detail add/drop without changing ground truth). Compare verdict/score stability when:

- **Core-locked:** only core criteria bind
- **Full genome:** core + peripheral domain criteria bind

## Outer Binary Ideal State Criteria

1. **[outcome]** Noise protocol is fixed in advance (≥3 paraphrases per golden sample; no change to true pursue/kill label).
2. **[outcome]** Core vs peripheral criterion lists are pre-declared (from exp-011).
3. **[outcome]** Stability metric pre-registered (e.g. verdict agreement rate; score band movement ≤ stated margin).
4. **[outcome]** Core-locked path shows **≥** full-genome path stability on verdict agreement **or** full-genome is within stated margin of core (canalization claim calibrated either way with numbers).
5. **[guardrail]** Noise must not invent evidence that would honestly flip a kill to pursue under human judgment (documented review).
6. **[economic]** ≤4 samples × 3 paraphrases × 2 binding modes (manageable batch).
7. **[guardrail]** No topology mutation; anti-loop fixtures still respected.

## Benefit / Cost Gate (pre-registered)

1. Declare core/peripheral lists.
2. Build paraphrase set.
3. Evaluate under both binding modes.
4. Compare stability; update core definition if needed.

## Key Insight

Verdicts are canalized, but **not because of the core genome**. `evaluateIdea` scores **intake fields** with regexes; custom criteria only affect `criteriaCheck` wording. When both core-locked and full-genome sets PASS the maker-checker, dimension scores (and verdicts) are identical. Core vs peripheral is therefore **untestable as a canalization mechanism** until an idea-vs-criteria probe exists (same architectural gap as exp-010).

Ship-rule reading: core is *not more stable* empirically, so we must **not** treat “slow-evolving because canalized” as measured. We **keep** {c6,c7} as core for independent reasons already in exp-011: they are universal guardrails (evidence honesty, scope) that should require `allowCore` + evidence to mutate (error-threshold + purifying), not because paraphrases bounce off them.

**KEEP scope:** keep CORE_IDS. Do not claim measured canalization advantage. Re-run when a real binder exists.
