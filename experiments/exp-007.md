## Task
Run the full multi-stage curriculum pipeline (generate → enrich → validate → pack/PDF) under gxp with Hybrid Verification, hierarchical Experience Memory of quality failures, and multi-agent specialization (structure vs content vs critic).

## Outer Binary Ideal State Criteria

3. Multi-agent specialization produces measurable gains over a single-loop baseline.
4. Any topology promotion or rewrite is gated and justified by repeated failure data.
5. Final curriculum packs meet deterministic schema and quality gates.

### Pipeline stages as GXP-style nodes
1. **generateCurriculumPack** — structure / skill arcs → skeleton JSON (own loop + tests)
2. **enrichPack** — pedagogical merge + quality gates (`review_assessment`, provenance, no residual skeleton; `--strict-enrich` exits 3 on failure)
3. **validate-pack.mjs** — AJV schema validation (hard deterministic gate)
4. **pack-to-pdf** — export (family vs QA variants)
5. **Human approval gate** — sellable / parked / needs_human_review

Each stage has binary pass/fail surfaces (schema, strict-enrich, tests). This satisfies Criterion 1.

### Ideal State Criteria already present
`.ai/tasks/000-mvp-ideal-state-criteria.md` defines 8 binary criteria (schema compliance, level match, skill coverage, method fidelity, provenance & review, pack completeness, GXP discipline, dual-use ready). Verification plan includes schema scripts + skill coverage + human pedagogical checklist.

### Experience Memory of quality failures (Criterion 2)
`.ai/failures/` already captures repeatable failure modes (generic companion filler, hardening quality gates, trees review blockers, hybrid multimodel review, process failures such as verification-wrapper swallowing exit codes, PowerShell escaping, etc.). `ratings.jsonl` records run outcomes. This is practical Experience Memory; the gap is hierarchical structure + automatic write-after-verification + cross-run retrieval that improves topology/prompts.

### Multi-agent specialization (Criterion 3)
Modules already separate structure generation, content enrichment, schema criticism, and PDF packing. GXP workflow phases enforce specialization of roles (brief writer, implementer, verifier, failure capturer). Concurrent multi-agent graph is not yet explicit; sequential + human gates are the current topology. Measurable gains appear as approved packs (birds, trees, hybrid birds 4-week sellable) vs parked laser-safety (deferred until equipment-specific).

### Topology discipline (Criterion 4)
Laser Safety Level 1 pack was deliberately **parked** with a decision record (`.ai/decisions/001-park-laser-safety-per-equipment.md`) rather than forced through approval. No uncontrolled topology mutation observed. Full GXP core install remains deferred by decision (000).

## Key Insight
curriculum-forge is already a multi-stage GXP pipeline with explicit Ideal State Criteria, per-stage deterministic gates, and a living failures ledger. It maps cleanly onto gxp layers: each stage is a GXP-style loop; enrich quality gates act as Hybrid Verification (inner content refinement + outer hard gate); failures/ + ratings supply Experience Memory of quality failures; modular scripts + workflow phases provide specialization. The highest-leverage next control-plane step is upgrading the failures ledger into hierarchical Experience Memory that is consulted on subsequent pack runs (and optionally drives gated topology proposals, e.g. when enrichment quality failures repeat). Concurrent multi-agent graph is optional until coordination failures appear.

**Recommendation:** Treat current pipeline as the multi-stage + Hybrid baseline. Next increment under the builder invariants: hierarchical Experience Memory over `.ai/failures/` patterns so quality failures improve future generate/enrich runs without uncontrolled mutation.
