## Promote — ideas to test

### P1. ISC Pin Set under compaction

**Concept:** When the harness compacts context, a **pin set** of versioned Ideal State Criteria + Anti-ISC ids is excluded from lossy summary; pin-fail writes a **CI-EM** record (criterion id + mode `compaction_drop`).

**Nearest art:** Governance Decay / ConstraintRot (arXiv:2606.22528); Lost in Compaction / CompInt; Constraint Pinning (~47 tokens restores 0% violation).

**Their result:** Soft organizational policies decay 8.3× harder than hard safety norms; pinning works; presence ≠ behavioral survival for residues.

**Residual gap:** Pin object is generic “session constraint,” not **versioned ISC genome + Anti-ISC**. No measured link from pin-fail → **criterion-indexed** failure memory as topology/session fuel.

**Proposed test:** Long-horizon session with compaction; measure violation when pin set = ISC/Anti-ISC vs generic pin vs no pin; count CI-EM writes on drop.

**Dispose:** **promote**

---

### P2. Ideal State Diff as sole skill changelog

**Concept:** Skill versions are admitted only if accompanied by a structured **ISC delta** (added/removed/mutated criteria + evidence refs). Prose-only SKILL.md edits are non-committable.

**Nearest art:** Versioned skills/registries; agentic fitness functions with versioned rubrics; PACE-style acceptors for prompts/skills (not ISC-shaped).

**Their result:** Skills are versioned artifacts; composition and trust schemas exist; changelogs remain human prose.

**Residual gap:** **ISC-diff as the only legal changelog** for a control-plane skill (ISCP-shaped), with commit rejected if delta missing or adversary games rise.

**Proposed test:** Two skill edits (prose-only vs ISC-delta); commit gate pass/fail; downstream thin/plus behavior unchanged only when delta commits.

**Dispose:** **promote**

---

### P3. Topology Stake Certificate (unfixed weight only)

**Concept:** Any τ3 topology proposal must attach a certificate listing CI-EM ids whose failures are **still unfixed** in product; remediated-only weight → automatic **reject** (exp-015 formalized).

**Nearest art:** Shadow/canary deploys; MemoRepair cascade invalidation; AgentOps drift; gated self-mod (PACE acceptors).

**Their result:** Canaries and memory invalidation exist; “don’t rebuild what you fixed” is folklore, rarely a **hard pre-τ3 artifact**.

**Residual gap:** Mandatory **stake certificate** keyed to criterion-class unfixed weight, measured by golden ISC delta = 0 on fixed-bug stakes.

**Proposed test:** Replay exp-015-class proposals with/without certificate; false-commit rate; zero product topology change in harness.

**Dispose:** **promote**

---

### P4. Soft-close detector orthogonal to ISC wording

**Concept:** A first-class **soft-close / POP-gaming** gate that scores *intent patterns* (brand, engagement, see-what-happens) independent of `checkCriteria`-style wording scores.

**Nearest art:** SpecEval; PReMISE rubric gaming; reward-hacking surveys; product POP scorers (the reference engine already partial).

**Their result:** Rubric gaming and spec adherence are studied; exp-010 showed ISC wording PASS while soft-close lives in scorers.

**Residual gap:** Treat soft-close as **control-plane Anti-ISC node** with binary certificate, not a buried dimension score—portable across products.

**Proposed test:** Ambiguous pursue/kill seeds; measure KILL/certificate rate with orthogonal detector vs wording-only ISC; no engine topology change.

**Dispose:** **promote**

---

### P5. Cross-skill ISC conflict gate

**Concept:** When ≥2 skills load, compute **ISC union conflicts** (contradictory criteria / Anti-ISC). On conflict: refuse compose, or force thin collapse—do not silent-merge.

**Nearest art:** Skill composition cliff (gains collapse at 4+ skills); SkillComposer; agentskills composition graphs; no standard ISC conflict protocol.

**Their result:** Composition degrades; ~1/5 skills can hurt; format lacks conflict signaling.

**Residual gap:** **Conflict detection on Ideal State Criteria sets** as the composition gate, not only skill count or embedding overlap.

**Proposed test:** Pair skills with known contradictory ISC; measure silent-merge harm vs conflict-gate refuse/collapse.

**Dispose:** **promote**

---

### P6. CI-EM survival under compaction

**Concept:** Criterion-indexed failure records must be **pinned or rehydrated** across compaction; measure TP/TN transfer precision before vs after compact when CI-EM is/isn't pinned.

**Nearest art:** Governance Decay (constraints); agentic memory staleness; FEMA/failure episodic memory—not CI-EM×compaction.

**Their result:** Constraints decay under compaction; operational memory needs expiry; cascade repair exists for invalidated descendants.

**Residual gap:** **CI-EM ids as pin targets** and measured transfer precision collapse when unpinned.

**Proposed test:** Seed CI-EM; compact; retrieve P1; precision vs pinned control.

**Dispose:** **promote**
