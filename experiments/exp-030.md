## Task

Build a **formal commit gate** for Ideal State Criteria mutations: given incumbent genome G and candidate G′, decide COMMIT | HOLD using **paired evaluation on a frozen instance set**, not a single adversary score tick.

Primary signals (deterministic preferred):

- High-severity game count from the Phase 2 adversary protocol on each sample’s criteria text
- `checkCriteria` / sample contract stability (FAIL→KILL, anti-loop, score bands)
- Optional: binary probe outcomes if a probe harness exists; do not invent LLM-as-judge as the sole gate

The gate must implement purifying selection: **no evidence → HOLD**. Core loci remain locked unless `allowCore` + evidence (exp-011).

## Outer Binary Ideal State Criteria

1. **[outcome]** Protocol document defines: instance set D, incumbent vs candidate comparison, discordant-pair or equivalent paired rule, stop/commit threshold, α (false-commit target).
2. **[outcome]** On a controlled suite with **≥3 noisy mutations** (should HOLD) and **≥1 true harden** from exp-010 lineage (should COMMIT), empirical false-commit rate on noisy set is **0** at the chosen threshold, and the true harden is COMMITted.
3. **[outcome]** Greedy baseline (commit if high-severity games strictly decrease on any single sample) is measured on the same suite; gate is **not worse** on true-positive rate and **strictly better** on false-commit rate.
4. **[guardrail]** Sample contracts still pass after any COMMIT (`npm test` the reference engine relevant suites).
5. **[guardrail]** Core genome mutation without `allowCore` is always HOLD/reject.
6. **[economic]** ≤1 adversary pass per (sample × candidate) evaluation; no product topology change; pure helper only.
7. **[outcome]** Decision KEEP | SHADOW | ABANDON recorded with gate arithmetic.

## Key Insight

Greedy “any sample improved” is the false-commit engine: N4 drops high-severity games on 3/4 ideas (6→5, 6→5, 5→4) while **raising** them on vague (4→5) and breaking `checkCriteria` / pursue→kill on strong. The discordant-pair rule (n01 must be 0) plus contract regression HOLDs it. The exp-010 harden is unanimous (n10=4, n01=0) and preserves gold verdicts, so it COMMITs.

This is **not** PACE. PACE (arXiv:2606.08106) commits prompt/skill edits from task-accuracy sequential tests. The object here is an **ISC genome** under adversary game-escape counts on a frozen 5-row D. Empirical α=0 on that D is not an anytime-valid e-process on GSM8K. Do not claim priority or “beats PACE”.

Partial OR-strip of c5 (not in the noisy suite) would also drop high games without contract regression — the metric cannot distinguish that incomplete harden from H1 without extra text-matching. Out of suite; not claimed solved.
