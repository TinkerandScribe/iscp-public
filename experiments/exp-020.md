# gxp-exp-020: Transfer Fitness (Gated Horizontal Gene Transfer)

**Campaign:** [Criteria Evolution](CAMPAIGN-criteria-evolution.md) · Phase 2b · Evo-bio  
**Status:** Executed 2026-08-25 — **KEEP** (P1 default; P0 anti-pattern)  
**Depends on:** exp-012 CI-EM with `transfer_scope`  
**Clock:** τ2  
**Surface:** the reference engine ↔ curriculum-forge failure classes; optional laser parked fixture

## Evolutionary hypothesis

**Horizontal gene transfer + reproductive isolation:** Transfer of failure knowledge across workflows can increase fitness (correct reuse) or create sterile/harmful hybrids (contamination). Explicit `transfer_scope` (`workflow` | `family` | `ecosystem`) plus quarantine should improve reuse/contamination ratio vs unrestricted transfer.

## Task

Using CI-EM entries, compare three transfer policies on a fixed scenario set:

- **P0 Unrestricted:** any failure may inform any workflow  
- **P1 Family-gated:** only same-family transfer (e.g. idea-evaluation family)  
- **P2 Quarantined ecosystem:** ecosystem transfer only with explicit quarantine review step

Measure true-positive reuse vs false transfer (contamination).

## Outer Binary Ideal State Criteria

1. **[outcome]** ≥4 transfer scenarios pre-registered: ≥2 should-reuse, ≥2 should-quarantine (include laser-safety → nature-study style mismatch).
2. **[outcome]** Each policy P0/P1/P2 is applied; outcomes labeled TP reuse / FP contamination / TN quarantine / FN missed reuse.
3. **[outcome]** Primary metric: precision of transfer (TP / (TP+FP)) and recall of needed reuse (TP / (TP+FN)).
4. **[guardrail]** Laser parked / domain-mismatch cases must not produce auto-apply under P1/P2.
5. **[outcome]** Recommended default scope recorded for the reference engine and curriculum-forge.
6. **[economic]** Offline labeling OK; no vector DB required.
7. **[guardrail]** No topology activation; memory policy only.

## Benefit / Cost Gate (pre-registered)

| Axis | Threshold |
|------|-----------|
| **Benefit** | P1 or P2 strictly higher precision than P0 at non-worse recall **or** documented tradeoff curve |
| **Cost** | Offline scenario pass only |
| **Ship rule** | Adopt winning scope as CI-EM default write/read rule; keep P0 as anti-pattern |

## Method

1. Build scenario card deck from real failures (exp-012 seeds).
2. Simulate retrieval under P0/P1/P2.
3. Score confusion matrix; choose default scope.

## Key Insight

Unrestricted HGT looks like “more memory” and is how laser-safety (equipment-specific, parked) contaminates a nature-study run. Family gating costs **zero recall** on this seed deck and recovers 29 percentage points of precision. That is reproductive isolation as an engineering default, not a metaphor.

**KEEP scope:** `retrieveCiEm(query, "P1")` is the default. Writes keep `transfer_scope` as declared (laser = ecosystem). Do not auto-call `retrieveWithQuarantineReview` with a pre-filled reviewed set.

- Cost: offline → **pass**
