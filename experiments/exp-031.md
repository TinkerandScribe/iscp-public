## Task

Upgrade Phase 2 **Refusal Certificates** into a **Refusal Digest**: a single structured document per refusal event that a **later process can re-verify offline** from the digest fields + cited evidence refs—without re-running the full agent and without becoming a second scorer.

Minimum digest fields:

```text
digest_id, workflow, anti_isc_ids[],
evidence_refs[] (paths or quotes),
forbidden_outcomes[] (what must remain false),
timestamp, schema_version,
content_hash (over canonical JSON of the above without the hash)
```

Verify algorithm (deterministic):

1. Recompute content_hash; match.
2. Confirm each `anti_isc_id` is in the standing Anti-ISC list.
3. Confirm each evidence_ref resolves (file exists or quote non-empty).
4. Confirm digest does **not** assert a pursue/approve outcome.

Optional later (out of scope for this exp): signatures. This exp is **offline re-verify without crypto** first.

## Outer Binary Ideal State Criteria

1. **[outcome]** Schema + `emitRefusalDigest` + `verifyRefusalDigest` pure helpers exist and are tested.
2. **[outcome]** 100% of Phase 2-style refusal events in the test set (anti-loop kill, laser park) produce digests that **verify offline**.
3. **[outcome]** Tamper cases fail verify: flipped anti_isc_id, empty evidence, mutated hash, digest that claims pursue.
4. **[guardrail]** Strong pursue samples still pursue; digest emission is not wired into `decideVerdict`.
5. **[outcome]** Digests store in CI-EM-compatible form (`mode: refusal_digest` or extension of `refusal`).
6. **[economic]** ≤1 structured write per refusal; 0 model passes for emit/verify.
7. **[outcome]** KEEP | SHADOW | ABANDON recorded.

## Key Insight

The digest is **memory of a refusal**, same as exp-013 certificates, plus an offline check that does not re-run `evaluateIdea`. Hash + standing Anti-ISC + evidence resolve + “must not claim pursue” is enough to catch the listed tampers. It still does **not** decide kills. Wiring this into `decideVerdict` would be over-refusal; that remains out of scope.

This is not an IETF Refusal Digest for legal/compliance use, and it is not signed. Claim is: *product-workflow offline re-verify for ISCP Anti-ISC events*.
