## Evolutionary hypothesis

**Epistasis:** Fitness effect of mutating criterion *i* depends on the state of criterion *j*. Independent single-criterion hardens can understate (or reverse) the effect of joint hardens—especially among POP / evidence / soft-close related criteria.

## Task

Select ≥3 criterion pairs with plausible interaction (e.g. POP closedness × evidence honesty; weasel ban × pain threshold). Measure game escapes and verdict shifts under:

- baseline genome
- mutate *i* only
- mutate *j* only
- mutate *i* and *j*

Detect non-additive interaction (epistasis) vs additive independence.

## Outer Binary Ideal State Criteria

1. **[outcome]** ≥3 pairs pre-registered with rationale before mutation.
2. **[outcome]** For each pair, all four conditions run (baseline, i, j, i+j) with same evaluate+adversary protocol.
3. **[outcome]** Epistasis is declared only with a pre-registered rule, e.g. interaction residual on high-severity games or verdict mismatch rate exceeds additive prediction by a stated margin.
4. **[outcome]** At least one pair is predicted *independent* as a negative control.
5. **[guardrail]** Mutations remain evidence-styled hardens (not random noise); no topology change.
6. **[economic]** ≤16 evaluate+adversary runs total (3 pairs × 4 + margin).
7. **[outcome]** Design implication recorded: genome mutation policy must / need not consider pair tests before multi-criterion hardens.

## Method

1. Pre-register pairs + independence control.
2. Apply single/joint hardens from exp-010-style suggestions.
3. Score games + verdict deltas.
4. Compute interaction residual; write Results.

## Key Insight

On the **scripted exp-010 detector**, game counts are almost per-criterion: hardening c1 removes c1 games regardless of c2's state, so joint effect equals the sum. That is a property of a **non-interacting detector** (regexes fire per text blob), not proof that a future idea-vs-criteria probe would be additive. The honest policy: **do not require pair-checks for text-level hardens**; revisit epistasis if a checker ever scores *pairs* of criteria against intake.

Predicted-epistatic pairs were **wrong**. Failures are data: intuition about POP/pain coupling did not show up in high-severity counts.

**KEEP scope:** document independence assumption for the current adversary. Do not add a pair-check gate to `genome.mutate`.
