# gxp-exp-001: Binary Search Coding Task

## Task
Implement a correct `binary_search(arr: list[int], target: int) -> int`, full unit tests covering edge cases, and a short verified summary of complexity + protected failure modes.

## Outer Binary Ideal State Criteria
1. Function correct on comprehensive test suite (empty, single, ends, middle, not-found, duplicates, negatives).
2. Test suite ≥ 8 distinct cases and all pass.
3. Summary accurately states O(log n) time / O(1) extra space and lists real failure modes the tests cover.
4. No unhandled exceptions / no unsupported claims.
5. Deterministically verifiable.

## Results

### Variant A — Pure GXP-style Loop
- Success after 3 outer iterations.
- Clean failure capture.
- Recovered from injected failure by pivoting.

### Variant B — Hybrid Verification Node
- Success after 2 outer iterations.
- Internal self-verification reduced outer retries.
- Cleaner recovery from injected failure.

## Comparison

| Metric | Pure GXP | Hybrid |
|--------|----------|--------|
| Task success | Yes | Yes |
| Outer iterations | 3 | 2 |
| Injected-failure recovery | Clean | Cleaner |
| Failure-capture completeness | High | High (richer) |
| Observability | Good | Better |

## Key Insight
Hybrid Verification reduced outer-loop cost while preserving the hard external gate and the four builder invariants.
