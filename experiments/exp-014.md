# gxp-exp-014: Multi-Timescale Control Clocks (τ1–τ4)

**Campaign:** [Criteria Evolution](CAMPAIGN-criteria-evolution.md) · Layer 5  
**Status:** Executed 2026-08-25 — **KEEP**  
**Depends on:** process discipline (ran alongside 010–013 as rules-only)  
**Clock:** meta (governs all clocks)  
**Surface:** gxp session practice + experiment notes across the reference engine / curriculum-forge

## Task

Separate four control timescales so task execution, session memory, topology change, and criteria evolution cannot collapse into one unsupervised blob. This experiment is **rules + compliance measurement**, not a new runtime feature.

## Clocks

| Clock | Object | Allowed cadence |
|-------|--------|-----------------|
| **τ1 Task** | Single GXP/Hybrid node execution | seconds–hours |
| **τ2 Session** | EM writes, anti-loop counters, session notes | hours–days |
| **τ3 Topology** | Graph structure, stage edges | only after CI-EM weight + explicit exp |
| **τ4 Criteria** | Ideal State genome mutations | only after adversary/evidence + explicit exp |

## Outer Binary Ideal State Criteria

1. **[outcome]** Clock rules are published in this brief and referenced by subsequent Phase 2 exps.
2. **[outcome]** In a sample of ≥5 documented work sessions (or exp runs), **zero** τ3 topology edits occur inside a τ1 task without an explicit topology experiment id.
3. **[outcome]** τ4 criteria mutations appear only inside exp-010/011 (or successors), never as drive-by edits during pack generation.
4. **[guardrail]** τ1 work may write τ2 memory; τ2 may not silently promote τ3.
5. **[outcome]** Violations, if any, are logged as process failures (CI-EM mode `clock_violation`).
6. **[economic]** No extra model cost—discipline only.
7. **[guardrail]** Four builder invariants remain explicit on every exp brief.

## Benefit / Cost Gate (pre-registered)

| Axis | Threshold |
|------|-----------|
| **Benefit** | 0 unscoped τ3/τ4 changes across the observation window |
| **Cost** | ≤5 minutes process overhead per session to tag clock |
| **Ship rule** | Adopt as standing campaign rule if benefit met |

## Method

2. Review session notes / commits for violations over the observation window.
3. Record compliance rate.

## Key Insight

Clocks work when they are **commit-visible**: if τ3/τ4 cannot land without an experiment id in the brief, the observation is cheap. The failure mode to watch is a “helpful” engine.ts edit during a τ1 bugfix that is actually a τ4 criteria change (e.g. relaxing `checkCriteria`). exp-010 already recorded the temptation; this window did not repeat it.

**KEEP scope:** standing rule. Tag every Phase 2 Results header. Do not build a scheduler.
