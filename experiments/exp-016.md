# gxp-exp-016: Mutational Load vs Error-Threshold Cap

**Campaign:** [Criteria Evolution](CAMPAIGN-criteria-evolution.md) · Phase 2b · Evo-bio  
**Status:** Executed 2026-08-25 — **KEEP** (error-threshold as standing τ4 rule)  
**Depends on:** exp-011 Criteria Genome (stable ids + mutation path)  
**Clock:** τ4  
**Surface:** the reference engine criteria sets on SAMPLE_IDEAS + weakened controls

## Evolutionary hypothesis

**Error threshold (Eigen):** If the rate of concurrent criteria mutations exceeds a threshold, heritable structure (probe reliability, stable verdicts on golden sets) collapses. Capped mutation should preserve held-out contracts better than unconstrained concurrent mutation under the same total edit budget.

## Task

Compare two regimes on the same golden criteria lineage:

- **Regime A — Error-threshold cap:** at most one mutation class per epoch (harden *or* split *or* tag change), evidence-gated.
- **Regime B — High mutational load:** multiple concurrent criteria edits in one epoch (same total character/token edit budget as A), weakly gated or ungated.

Measure degradation of held-out the reference engine contracts and adversary game escapes.

## Outer Binary Ideal State Criteria

1. **[outcome]** Both regimes are applied to the same starting genome snapshot; total edit budget (characters or criterion-count) is matched and recorded.
2. **[outcome]** Held-out sample contracts (`npm test` / SAMPLE_IDEAS verdict bands) are scored after each regime.
3. **[outcome]** Primary comparison is recorded: Regime A vs B on (a) contract pass rate, (b) high-severity adversary games, (c) false PASS on deliberately soft control set.
4. **[guardrail]** No topology change; no product default switch—analysis only unless A clearly dominates and gate is met.
5. **[outcome]** Decision: **keep error-threshold as standing τ4 rule** / **weaken** / **abandon load concern** with numbers.
6. **[economic]** ≤3 full evaluate+adversary cycles per regime on the sample set.
7. **[guardrail]** Four builder invariants upheld; purifying default remains for any production path.

## Key Insight

Ungated concurrent edits that inject weasel into a **core** locus (c7, no numeral) collapse contracts via the *existing* `checkCriteria` weasel gate: every sample becomes KILL. That is Eigen-like: load hits a conserved probe and heritable verdict structure dies. A single evidence-gated peripheral harden (c5) preserves all four contracts and *reduces* games (c5-escape-or removed). Axis (c) going to B is not a reason to drop the cap: B's "fewer false PASS" is the same weasel trip, not a better soft-control detector. Cap the production path at **one mutation class per epoch**.

**KEEP scope:** encode max-one-mutation-class in `genome.mutate` (already the API). Do not use `mutateBatchUngated` in product.

### Gate arithmetic

- Benefit: A better on ≥2 axes (contracts + games) → **pass**
- Cost: 3 cycles → **pass**
- Ship rule: **KEEP** error-threshold
